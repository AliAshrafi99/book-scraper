
# 📚 Book Scraper

A web scraper for books.toscrape.com built with Python.

## Technologies
- Python
- Camoufox / Playwright
- Pandas

## What it does
- Scrapes book names and prices from Historical category
- Exports data to CSV and Excel files

## How to Run
pip install pandas openpyxl camoufox
python Book Scraper.py
